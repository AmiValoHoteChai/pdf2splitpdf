# pdf2splitpdf

> 100% Client-Side In-Browser PDF Splitter & Partition Tool

## Features

- **Chunk Splitting**: Choose any page count (e.g. split into pieces of 5 pages each).
- **Custom Page Ranges**: Specify exact page ranges (e.g. `1-3, 4-7, 8-12`).
- **Single Page Extraction**: Split every page into its own individual PDF.
- **Equal Parts**: Divide documents evenly into $N$ equal files.
- **100% Client-Side**: Powered by WebAssembly and `pdf-lib` — files never leave your browser.
- **ZIP Export**: Download all split pieces in a single compressed ZIP file or download individually.

## Getting Started

```bash
npm install
npm run dev
```
